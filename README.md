# Holberton Web Back End

Module back-end de Holberton School consacré à la programmation asynchrone en Python.

## Projets

| Dossier | Contenu |
|---|---|
| `python_async_function` | Coroutines avec async et await, exécution concurrente avec asyncio, mesure du temps d'exécution |
| `python_async_comprehension` | Générateurs asynchrones et compréhensions asynchrones |

## Prérequis

- Python 3.8 ou plus récent
- Annotations de type et style PEP 8

## Utilisation

```bash
cd python_async_function
python3 0-main.py
```
